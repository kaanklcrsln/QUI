about=QUI opens a simplified, clickable mockup of the QGIS interface (menus, toolbars, Layers and Browser panels, status bar, a sample dialog). Select any component and edit its colors, gradients, borders, corner radius, padding and per-state styles (hover, pressed, selected, checked, disabled) with a live preview and a WCAG contrast check, plus the global program font. Start from the Glass Dark, Glass Light, Minimal or High Contrast presets. When you are happy, apply the theme to QGIS: a 15-second confirmation reverts automatically if the result is unreadable, and Plugins > QUI > Restore Original QGIS Look brings back the exact original look at any time. Themes are saved as .qui.json and can be exported as regular QGIS UI themes. Available in English and Turkish. Styling uses Qt Style Sheets (QSS), so true background blur is not possible; QUI never changes map rendering or QGIS's own settings.
